# 🚀 LifeHub — Unified Desktop Dashboard

LifeHub is a clean, dark-mode desktop productivity dashboard built for macOS using Python and CustomTkinter.

## Features
- 📝 **Tasks & Goals:** Daily task tracking with interactive completion.
- 🔄 **Habit Tracker:** Recurring daily goal tracking with automatic saves.
- ⏱️ **Focus Timer:** Customizable Pomodoro-style focus timer.
- 📅 **Calendar Feed Sync:** Live schedule integration for Webcal/iCal feeds.

## 📥 Download
To download the standalone Mac app without running terminal commands:
1. Go to the **Releases** tab on the right side of this page.
2. Download **`LifeHub.zip`**.
3. Unzip and double-click **`LifeHub.app`** to launch!
